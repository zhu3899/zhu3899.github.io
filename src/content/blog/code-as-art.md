## 先说结论

本站所有文章封面都不是图片，而是浏览器里一段约 100 行的 JavaScript 画出来的。**标题不同 → 随机种子不同 → 画面完全不同**。

## 核心思路：流场

想象一张纸上布满了看不见的箭头（向量场），每个位置的箭头方向由一个二维噪声函数决定。现在让几百个粒子从随机位置出发，沿着箭头方向小步前进，并把走过的轨迹画下来 —— 就得到了流动感的线条画。

```text
粒子起点 (x, y)
    ↓
角度 a = noise(x * s, y * s) * π * 3
    ↓
前进一小步：(x, y) += (cos a, sin a) * len
    ↓
重复 30~100 次，连成一条线
```

## 关键实现

### 1. 可复现的随机数

`Math.random()` 每次刷新结果都不一样，无法做到「同一篇文章永远同一张封面」。所以需要种子随机数生成器（PRNG）：

```ts
export function hashSeed(str: string): number {
  let h = 1779033703 ^ str.length;
  for (let i = 0; i < str.length; i++) {
    h = Math.imul(h ^ str.charCodeAt(i), 3432918353);
    h = (h << 13) | (h >>> 19);
  }
  return (h ^= h >>> 16) >>> 0;
}

export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a |= 0;
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

### 2. 低透明度叠出层次感

单条线并不好看，秘密在于**大量半透明线条的叠加**：

```ts
ctx.strokeStyle = color;
ctx.globalAlpha = highlight ? 0.3 : 0.05 + rand() * 0.09;
ctx.lineWidth = highlight ? 1.6 : 0.5 + rand() * 1.1;
```

其中约 8% 的线条被标记为 `highlight`，透明度更高、更粗 —— 它们是画面里的「主角」。

### 3. 配色收敛在青紫区间

完全随机的色相容易脏。把基础色相锁定在两个相邻区间（青色 ~190°、紫色 ~265°），中间再混一个过渡色：

```ts
const h1 = 178 + rand() * 24;   // 青
const h2 = 252 + rand() * 30;   // 紫
```

## 还能怎么玩

| 变量 | 改动效果 |
| ---- | -------- |
| `noise` 的频率 `s` | 调大 → 线条更卷曲凌乱；调小 → 更舒展平滑 |
| 步长 `len` | 调大 → 线条呈折线感，有电波味 |
| 起点分布 | 改为沿同心圆分布，会得到放射状结构 |
| 颜色映射 | 让颜色跟随噪声值渐变，画面更有纵深 |

## 小结

生成艺术最迷人的地方在于：**规则是你写的，但结果是你们共同完成的**。改一行参数就能得到一整个系列的作品 —— 这大概就是程序员的浪漫。
